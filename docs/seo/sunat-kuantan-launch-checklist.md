# Sunat Kuantan launch and measurement checklist

Use this checklist after the Sunat page has been deployed. Items marked **Owner action** are performed in Google products by a verified clinic representative; they are not changes made by the deployed website. Completing these steps cannot assure a particular position, traffic, reviews, or a timeframe for Google to show the page.

## Before launch: deployed-site checks

These are checks of the public deployment, not actions in a Google account.

- [ ] Confirm the public canonical page loads: `https://klinikawfa.com/services/sunat-kuantan/`.
- [ ] Confirm the page's canonical URL is `https://klinikawfa.com/services/sunat-kuantan/` and that it appears in `https://klinikawfa.com/sitemap.xml`.
- [ ] Confirm the page contains only accurate clinic information and a working appointment path: `https://klinikawfa.com/appointment`.
- [ ] Record the deployment date and the person who checked the live page in the baseline table below.

## Google Business Profile: owner actions

Perform these in the clinic's verified [Google Business Profile](https://www.google.com/business/) account. Do not create a duplicate profile, use a virtual address, or add services the clinic does not genuinely provide.

- [ ] Confirm the verified business name remains the exact real-world clinic name.
- [ ] Confirm address, map pin, telephone, regular hours, and special hours match klinikawfa.com.
- [ ] Set the website to `https://klinikawfa.com/` and appointment link to `https://klinikawfa.com/appointment`.
- [ ] Add a factual Sunat/circumcision service description and use the canonical Sunat URL where a service URL is supported.
- [ ] Upload current clinic/service-environment photos with no patient-identifying information.
- [ ] Publish one factual Sunat preparation or aftercare post linking to the canonical page.
- [ ] Save the date each change was completed, the profile editor, and a screenshot or account note for clinic records.

### Honest review request

Use this wording only with patients who have received care, without conditioning it on a positive rating or offering an incentive:

> Terima kasih kerana mendapatkan rawatan di Klinik Awfa. Jika anda selesa, kami menghargai ulasan jujur tentang pengalaman anda di klinik: [Google review link]

Do not ask specifically for a positive rating, selectively solicit only satisfied patients, compensate a patient for a review, or have staff write reviews for patients.

## Google Search Console: owner actions

Perform these in the verified Search Console property for `klinikawfa.com` after deployment.

- [ ] Submit `https://klinikawfa.com/sitemap.xml`.
- [ ] Inspect `https://klinikawfa.com/services/sunat-kuantan/`.
- [ ] Run **Test Live URL** and confirm crawl/indexing allowed.
- [ ] Request indexing once after the deployed page passes the live test.
- [ ] Record impressions, clicks, CTR, and average position for the target query groups.
- [ ] Record the sitemap submission status, URL Inspection status, live-test outcome, indexing-request date, and any reported blocking reason in the baseline table.

Request indexing only once for this deployment unless a material page correction is deployed. A request is not an indexing or ranking promise.

### Target query groups

Record each group separately where Search Console has sufficient data; do not infer missing data as zero rankings.

- `sunat Kuantan`, `khatan Kuantan`, and `circumcision Kuantan`
- `sunat bayi Kuantan`
- `sunat kanak-kanak Kuantan`
- `sunat dewasa Kuantan`
- `Klinik Awfa sunat` and branded clinic queries containing `Sunat`

## Review decisions

At 4 and 12 weeks, check whether the canonical page is eligible for indexing, whether the sitemap was processed, and how the approved query groups changed from baseline. If Search Console reports an error, document the exact message and route only a website issue to the site maintainer; profile ownership, verification, reviews, and Google account permissions remain owner-controlled actions. Do not promise or report a certain ranking outcome.
