# Google Search Console SEO handoff

This checklist is for the clinic owner after the website update is live. It helps Google recognise `https://klinikawfa.com/` as Klinik Awfa's official website. It does not guarantee a particular ranking or timing.

For the Sunat Kuantan page, use the separate [Sunat Kuantan launch and measurement checklist](sunat-kuantan-launch-checklist.md). It distinguishes owner-controlled Google Business Profile/Search Console actions from checks of the deployed site and records the baseline, 4-week, and 12-week reviews.

## 1. Check ownership in Google Search Console

1. Open [Google Search Console](https://search.google.com/search-console/).
2. Check whether either the `https://klinikawfa.com/` property or the `klinikawfa.com` Domain property is already verified.
3. If neither is present, click **Add property**, choose **Domain**, enter `klinikawfa.com`, and follow Google's DNS TXT verification instructions at the company that manages the domain's DNS records.

## 2. Submit the sitemap

1. In Search Console, select the verified Klinik Awfa property.
2. Open **Sitemaps**.
3. Enter `https://klinikawfa.com/sitemap.xml` and click **Submit**.

## 3. Ask Google to review the key public pages

Use **URL inspection** in Search Console to inspect each page below after deployment. If Google offers the option, choose **Request indexing**.

- `https://klinikawfa.com/`
- `https://klinikawfa.com/services/rawatan-telinga-kuantan`
- `https://klinikawfa.com/services/minor-surgery-kutil-kuantan`
- `https://klinikawfa.com/services/swab-test-demam-kuantan`
- `https://klinikawfa.com/services/pengurusan-berat-badan-kuantan`
- `https://klinikawfa.com/services/sunat-kuantan`

For the Sunat page, first run **Test Live URL**, confirm crawl/indexing is allowed, then request indexing once after it passes. Record the inspection result in the Sunat checklist.

For the home page, also check **Page indexing** and confirm the Google-selected canonical is `https://klinikawfa.com/`.

## 4. Keep Google Business Profile consistent

In [Google Business Profile](https://www.google.com/business/):

1. Set the website to `https://klinikawfa.com/`.
2. Make sure the clinic name, address, phone number, and opening hours match the website exactly.
3. Add relevant services that the clinic genuinely provides, such as ear treatment, minor surgery / wart treatment, swab testing, fever care, weight management, and circumcision.
4. Set the appointment link to `https://klinikawfa.com/appointment`.

## 5. Avoid competing websites

If the old Canva site is still public, make it link clearly to `https://klinikawfa.com/` as the official Klinik Awfa website. If you own and no longer need it, retire it instead. This helps avoid Google treating the old site and Klinik Awfa's main website as competing versions.

## 6. Track progress realistically

Record a starting point in Search Console for the following approved search themes:

- Klinik Awfa, Klinik KotaSAS, Klinik Kuantan
- rawatan telinga Kuantan
- minor surgery / kutil Kuantan
- swab test / demam Kuantan
- kurus / pengurusan berat badan Kuantan
- sunat bayi, kanak-kanak, dan dewasa Kuantan

Review clicks, impressions, average position, and indexed pages after 2, 4, 8, and 12 weeks. Search visibility usually takes time, and only Search Console data can show whether rankings have changed.
